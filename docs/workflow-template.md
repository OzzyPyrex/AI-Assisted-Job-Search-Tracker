# Job Search Research Workflow Template

## Objective

Find genuine, currently open vacancies that match a defined target profile, record the evidence in the tracker, and prioritise the strongest and freshest opportunities.

This workflow is research-only. It does not submit applications, upload CVs, contact employers, send LinkedIn messages, or complete application forms.

## 1. Configure the search

Define these details before research begins:

- Target locations: [cities, regions, remote or hybrid preferences]
- Target roles: [job titles and adjacent titles]
- Core skills: [tools, methods, industries, and qualifications]
- Seniority: [entry, junior, mid-level, senior]
- Right-to-work constraints: [private local note; do not commit personal details]
- Minimum salary or contract preferences: [optional]

Keep personal contact details, CV paths, immigration documents, and private account information in a local configuration file that is excluded from version control.

## 2. Search broadly

Use a mix of:

- Direct employer career pages
- Major job boards
- Specialist recruiters
- Public-sector and university portals
- Professional networks for vacancy verification and public hiring-team context

Prefer direct employer application links when available. Record both the application URL and the page used to verify the vacancy.

## 3. Validate every vacancy

Before adding or refreshing a row:

- Confirm the page is accessible and the vacancy appears open.
- Capture the employer, title, location, work mode, posting date, and closing date.
- Avoid inferring sponsorship, salary, or remote eligibility when the source is silent.
- Mark uncertain details as Needs verification.
- Check for duplicates using employer, title, and application URL.

- Apply immediately
- Strong option

- Low priority

## 5. Maintain the tracker

For each search session:

1. Add new verified vacancies.
2. Refresh open roles and deadlines.
3. Update application status and last-reviewed notes.
4. Resolve duplicates.
5. Review the dashboard in freshness, match-score, and closing-date order.

## 6. Responsible-use guardrails

- Keep application submission and outreach manual.
- Do not expose private profile data in a public repository.
- Do not store passwords, session tokens, one-time codes, or private browser data.
- Treat public recruiter profiles only as research context, not proof of vacancy ownership.
- Recheck every vacancy immediately before applying.
